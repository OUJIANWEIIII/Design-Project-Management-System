# 产品需求文档

## 1. 产品定位

工业设计项目池、排期与周工作总览系统是面向工业设计部门设计负责人的内部项目管理工具。

系统核心价值不是通用任务管理，而是围绕工业设计项目的提前录入、等级排期、设计师周安排、项目轮次、延期识别和企业微信群提醒，帮助设计负责人减少遗漏、看清负载、推进交付。

## 2. 使用场景

- 设计负责人提前录入项目，即使暂未确定设计师或开始时间。
- 项目正式安排后，系统按 A/B/C/D 等级生成工作日排期。
- 负责人查看本周每位设计师每天有哪些项目。
- 负责人识别设计师负载、延期项目、待反馈项目。
- 项目交付后进入待反馈，后续可开启下一轮设计。
- 负责人通过企业微信群提醒同步项目创建、交付、延期和每周工作安排。

## 3. 用户角色

当前未实现登录和权限系统。系统内的数据模型包含“设计负责人”和“设计师”两类人员，但这不是账号权限，只是项目业务角色。

当前业务角色：

- 设计负责人：负责项目管理、排期、推进、提醒。
- 设计师：参与项目设计工作，进入周排期和负载计算。

后续可规划：

- 管理员：管理系统配置、人员、Webhook。
- 设计负责人账号：管理部门项目。
- 设计师账号：查看个人排期、更新状态。

## 4. 功能模块

### 项目管理

- 新建、编辑、删除项目。
- 项目汇总统计与筛选。
- 项目详情查看。
- 项目状态管理。
- 未安排项目识别。

### 项目轮次

- 项目首次创建时生成第 1 轮。
- 项目提交待反馈后可开启下一轮。
- 每一轮可单独编辑等级、状态、设计师、开始时间、目标交付时间、备注。
- 可删除非唯一轮次。
- 删除当前轮后自动回到剩余最新轮次。

### 自动排期

- A/B 默认 8 个工作日。
- C 默认 6 个工作日。
- D 默认 2 个工作日。
- 默认跳过周六、周日。
- A/B/C 自动生成中途对齐节点。
- 若填写目标交付时间，按开始时间到目标交付时间的工作日窗口重新安排节点。

### 周工作总览

- 按周展示周一至周六。
- 每位设计师一行。
- 每天可显示多个项目。
- 显示项目等级、项目名、事业部、需求方、轮次、阶段。
- 显示设计师本周负载百分比。
- 延期项目在交付后继续显示“延期”。
- 待反馈、已完成、已暂停只影响操作当天，不覆盖历史日期。

### 成员管理

- 基础设置中维护设计负责人名单。
- 基础设置中维护设计师名单。
- 移除名单中的人员会标记为不活跃，不直接删除历史数据。

### 提醒管理

- 企业微信群机器人 Webhook 配置。
- 项目创建提醒。
- 对齐前提醒。
- 交付前提醒。
- 延期提醒。
- 每周工作安排提醒。
- 提醒记录查看、重发、复制、作废、删除。
- 已发送、失败、作废提醒记录超过 2 天自动清理。

## 5. 状态规则

项目状态：

- 未开始：项目已录入，但尚未正式推进。
- 进行中：项目正在执行。
- 待对齐：到达中途对齐节点或需要阶段对齐。
- 待反馈：已提交或交付后等待需求方反馈。
- 已完成：项目关闭。
- 已延期：超过交付时间仍需继续推进。
- 已暂停：项目临时暂停。

周工作总览规则：

- 周总览显示“日期事实”，不会把历史日期全部改成当前项目状态。
- 当天将项目改为待反馈/完成/暂停，只在当天显示该状态，未来不继续排期。
- 延期项目表示仍在推进，交付日后继续顺延显示“延期”。
- 未安排项目不进入周总览和负载计算。

## 6. 后续功能规划

以下为后续规划，当前未实现：

- 登录和权限管理。
- 项目操作日志。
- 设计师个人视图。
- 项目归档而非硬删除。
- 更完整的节假日工作日规则。
- 数据导入导出。
- 企业微信应用级消息或个人精准提醒。
- 部署到内网服务器并配置自动备份。
